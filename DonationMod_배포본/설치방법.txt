※ 해당 파일은 윈도우 기반으로 제작되어 윈도우 외 운영체제에서 정상적으로 작동하지 않습니다! ※


■ DonationMod 설치 방법

1. 팰월드 서버를 종료합니다.

2. 배포본 파일을 아래 위치에 복사합니다.

   팰월드 서버 설치 폴더\Pal\Binaries\Win64\

   예시:
   C:\Program Files (x86)\Steam\steamapps\common\PalServer\Pal\Binaries\Win64\

   복사 위치는 다음과 같습니다.

   - 배포본의 `ue4ss` 폴더
     → `Pal\Binaries\Win64\ue4ss\`에 병합

   - 배포본의 `dwmapi.dll`
     → `Pal\Binaries\Win64\`에 복사

3. 서버를 시작한 뒤 게임 채팅에서 테스트합니다.

   명령어:
   `!cztest 플레이어이름 금액`

   예시:
   `!cztest Money 20000`


※ 주의 사항

- 'donations.queue' 파일에는 제목·설명·빈 형식의 데이터를 넣지 마세요.
- 설정되지 않은 금액의 후원 데이터는 큐에서 자동 삭제됩니다.
- 'players.status', 'donations.queue', 스트리머 등록 요청·응답 파일은 서버 실행 중
  자동으로 생성·갱신됩니다.


■ 팰월드 인게임 명령어

▷ 치지직 등록
   !czr <팰월드닉네임> <채널ID>

   채널ID란?
   예시:
   https://chzzk.naver.com/f7e71c69f222a684ed3e323e025d1fa7

   위 주소에서
   f7e71c69f222a684ed3e323e025d1fa7
   부분이 고유번호입니다.

▷ 후원 테스트
   !cztest <팰월드닉네임> <후원금액>

   예시:
   !cztest 나루 1000

▷ 치지직 연결 해제
   !czu

▷ 치지직 연결 상태 확인
   !czs


※ 인게임 명령어 주의 사항

- 치지직 등록, 연결 해제, 연결 상태 확인, 후원 테스트는
  각 플레이어가 팰월드 인게임 채팅창에서 직접 입력해야 합니다.

- 후원 테스트는 실제 이벤트를 실행합니다.

- 의뢰자 외 다른 플레이어가 후원 테스트를 사용하지 못하게 하려면
  `!cztest` 명령어를 공유하지 말고, 의뢰자가 직접 입력해 주세요.

- 설정되지 않은 금액은 테스트할 수 없습니다.
  현재 예시의 `2,000원`은 설정된 등급이 아니므로 실행되지 않습니다.


■ 이벤트 관련 주의 사항

@ 슈퍼점프 후 체력이 적게 감소하는 현상은 팰월드 자체 동작에 따른 현상입니다.
@ 30,000원 이벤트는 다른 접속 플레이어가 있으면 그 플레이어에게 이동하고, 다른 플레이어가 없으면 랜덤 좌표로 이동합니다.
@ 슈퍼점프는 언리얼 엔진 물리 판정을 사용하므로 지형이나 구조물에 끼일 수 있습니다.
  이 경우 게임 내 긴급 탈출 기능을 사용해 주세요.
